# Sentinel AI — Fire & Smoke Detection System

## 📌 Project Overview

Sentinel AI is a computer vision application designed to detect fire and smoke in images and videos using YOLOv8. The application provides an interactive dashboard built with Streamlit to make detection results easier to review.

## 🎯 Project Objectives

* Detect fire and smoke in images and videos.
* Display detection results with bounding boxes and confidence scores.
* Provide an interactive interface for reviewing results.
* Record detection events and save snapshots for later review.

## 🛠️ Technologies Used

* Python
* YOLOv8
* Streamlit
* OpenCV
* Pandas

## 🚀 How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Ensure the YOLOv8 model weights are available locally.
4. Run the application:

```bash
streamlit run app_sentinel_dashboard.py
```
